# 两轴标定记录 · 2026-11-17

> 台架：平板 + MPU6050 + 两只 MG90S（A 在平板中心，B 在弯 90° 的摇臂上，两轴在 XY 面内互成 90°）
> 接线：A=GPIO6、B=GPIO7、I2C SDA=8 SCL=9、6050 地址 0x68、WHO_AM_I=0x68
> 方法：两只先回中，单只从 1300→1700（A）/1350→1650（B），每 50 µs 一步，停 300 ms 后取 8 次平均倾角

## 结果

| 项 | 舵机 A | 舵机 B |
|---|---|---|
| 主要影响的角 | pitch | roll |
| 400/300 µs 走完的角度变化 | 33.62° / 400 µs | −23.49° / 300 µs |
| **灵敏度（实测）** | **8.41 °/100 µs → 11.90 µs/°** | **7.83 °/100 µs → 12.77 µs/°** |
| 与 1:1 的偏差 | 0.934 倍 | 0.870 倍 |
| 对另一轴的影响（耦合） | roll 只变 −0.31° | pitch 只变 +0.06° |

**两轴正交、几乎零耦合**——这是本台架最关键的结论：A 只动 pitch，B 只动 roll，可以直接拆成两个独立的单轴闭环，不用解耦矩阵。

## 零点与重复性（问题在这）

- 1500/1500 静止时读数：pitch **−1.20°**，roll **+19.63°**
- A 扫回 1500 时：pitch −2.87°、roll +21.54°
  → **同一条 1500 指令，前后差 1.7°（pitch）/ 1.9°（roll）**，是模拟舵机的回差与迟滞，不是噪声
- 陀螺零偏（静置）：x 约 −6.6 °/s（这片偏大，固件里必须扣）

## 两个要处理的事

1. **roll 零点偏 19.63°，接近花键一个齿位（17.14°）**。现在要摊平，B 得多走约 +250 µs（到 ~1750），一侧行程几乎被吃光。建议把 B 的舵角拔下来转一个齿位重装，把这个偏差压回 ±5° 内。
2. 回差 ~1.9° 决定静态精度的下限：死区至少给它留 1°，否则舵机会在死区边缘来回蹭、发烫。
